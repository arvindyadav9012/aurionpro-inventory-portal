NMRC INVENTORY PORTAL V22 FINAL CODE CHECK
===========================================

1. Persistence / Live Sync
- Shared state remains on existing D1 sync table/API.
- New records receive a stable _recordId.
- Server merge now honours record deletion tombstones.
- Login/logout no longer restores deleted report rows from the central state.
- Station and Equipment Master deletions have tombstones so live sync cannot resurrect them.
- Default station/equipment values are re-seeded after a sync pull and pushed when newly added.

2. Deleted Records
- Normal Delete removes the row from its report and moves a copy to Deleted Records.
- Deleted rows remain hidden from normal reports after login/logout.
- Restore removes the deletion tombstone.
- Permanent Delete first sends the deleted record to the Google Drive backup endpoint, then removes it from portal Deleted Records.
- A permanent-deletion tombstone prevents another device/live sync from bringing the record back.

3. Google Drive
- Permanent-deletion JSON backup uses the stable recordKey as the Drive filename key.
- Existing Google Drive backup URL/configuration was preserved.
